## Overview

Research responses generated by AI models cite sources. The `Citation` component bridges the gap between a raw source name and a polished, interactive inline reference. It renders as a pill-shaped chip that can appear inline within prose or in a dedicated citations row.

## Props

```svelte
interface Props {
  source: string;           // Publisher name
  color?: string;           // Fallback dot color if favicon fails
  favicon?: string;         // Override favicon URL
  number?: number;          // Superscript citation number
  url?: string;             // Link destination
  class?: string;
  onclick?: (e?: unknown) => void;
}
```

## Favicon with Graceful Degradation

The component attempts to show a 10×10 favicon derived from the source name:

```svelte
const iconSrc = $derived(favicon ?? faviconUrl(source));
let iconError = $state(false);
```

If the `<img>` fires `onerror` (network failure, invalid domain, CORS block), `iconError` flips to `true` and the template swaps to a colored dot:

```svelte
{#if !iconError}
  <img src={iconSrc} alt="" onerror={() => iconError = true} />
{:else}
  <span class="rcite-dot" style="background:{color}"></span>
{/if}
```

This two-path rendering is critical because favicons from `faviconUrl()` depend on Google's favicon service. In offline contexts, private networks, or when Google's CDN has a hiccup, the image request will fail. Without the error fallback, the broken-image icon would break visual consistency across the entire citations row.

## Conditional Interactivity

The chip can be passive (just a label) or interactive (a clickable link). The component sets `role="button"` and `tabindex={0}` only when an interaction handler is present:

```svelte
role={onclick || url ? 'button' : undefined}
tabindex={onclick || url ? 0 : undefined}
```

This matters for accessibility — passive chips should not be in the tab order or announced as interactive elements to screen readers. The pattern avoids creating false affordances.

The fallback handler `url ? () => window.open(url, '_blank') : undefined` means the consuming AI model doesn't have to wire up an onclick manually; providing a `url` is sufficient.

## Superscript Numbers

The optional `number` prop renders a superscript citation index:

```svelte
{#if number != null}
  <sup class="rcite-num">{number}</sup>
{/if}
```

Note the use of `!= null` (loose inequality) rather than `!== undefined`. This deliberately includes `null` as falsy, so both explicit `null` and absent `number` prop skip rendering. The check also correctly allows `number={0}`, though zero-indexed citations are unusual in practice.

## Styling

The chip uses `white-space: nowrap` to prevent line-breaking mid-citation in flowing prose. The `display: inline-flex` with `vertical-align: baseline` keeps it sitting on the text baseline correctly when embedded in a paragraph.

## Known Gaps

- No error recovery for `faviconUrl` returning an invalid URL when `source` is undefined or null (the `faviconUrl` function itself handles null inputs, but calling code should still guard).
- The `onclick` event parameter type is `unknown`, providing no type-safe way for consumers to inspect what was clicked. A structured event payload (e.g. `{ source, url }`) would be more useful.
